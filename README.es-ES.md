# Comfy Code

Una versión personalizada de [Iosevka](https://github.com/be5invis/Iosevka) para programar cómodamente y sin distracciones.

## Características

- Letras de ancho fijo y sin serifas
- Anchos normales y condensados
- Estilos rectos y cursivas
- Ligaduras de programación deshabilitadas
- Paquetes TTF con sugerencias, TTF sin sugerencias y webfont

## Descarga e Instalación

Descarga la [última versión](https://github.com/zzhaolei/comfy-code/releases/latest) y elige el paquete adecuado para tu uso:

- `ComfyCode-hinted.zip` para uso en escritorio
- `ComfyCode-unhinted.zip` para archivos TTF sin sugerencias
- `ComfyCode-webfont.zip` para proyectos web

Extrae el archivo y luego instala los archivos TTF a través de tu sistema operativo o usa los archivos webfont incluidos y CSS en tu proyecto.
